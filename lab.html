A small-business style Windows environment built around Windows Server 2022. DC01 provides Active Directory and DNS for the corp.lab domain. CLIENT01 was installed, configured to use DC01 for DNS, joined to the domain, authenticated with a domain account and placed into the Workstations OU. A Workstation Baseline GPO was created and linked, and a successful policy refresh was performed.
